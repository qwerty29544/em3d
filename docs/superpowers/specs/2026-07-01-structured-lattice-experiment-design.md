# Structured Lattice Experiment Design

## Цель

Добавить воспроизводимый эксперимент для электродинамического моделирования регулярной решётки структурированных неоднородных включений в поле падающей плоской волны. Рабочий сценарий должен поддерживать сетку `100x100x100`, оценку итерационного параметра на грубой сетке `9x9x9`, запуск `SIM`, `BiCGStab`, `TwoStep`, визуализацию поля, ЭПР, норм/невязок решения на итерациях и внешние логи с итоговыми метриками.

## Архитектура

Новая логика выносится в `experiments/structured_lattice.py`, чтобы не перегружать `chapter06_em.py`. Фасад `experiments/chapter06_em.py` реэкспортирует публичные dataclass и функции, чтобы notebook мог использовать единый импорт.

Основные единицы:

- `InclusionSpec` — одно сферическое или эллипсоидальное включение с центром, радиусами и материалом `MaterialSpec`.
- `StructuredLatticeCase` — конфигурация эксперимента: сетка, область, волновое число, грубая сетка для `gamma0`, список включений и список солверов.
- `make_structured_lattice_case(...)` — builder регулярной решётки включений. По умолчанию создаёт рабочий case `N=(100,100,100)`, `coarse_N=(9,9,9)`.
- `build_structured_lattice_problem(case)` — строит `eps_tensor` как сумму/перезапись масок включений и возвращает `em3d.Problem`, `em3d.Operator`.
- `run_structured_lattice_experiment(...)` — полный эксперимент с логами, таблицами, JSON summary, ЭПР, field plots и residual plots.

## Численная постановка

По умолчанию используется регулярная решётка `5x5x5` включений в кубе `L=(1,1,1)`. Каждое включение задаётся эллипсоидом:

```python
((x - cx) / rx)**2 + ((y - cy) / ry)**2 + ((z - cz) / rz)**2 <= 1
```

Материал по умолчанию: `eps = 2.5 + 0.02j`. Падающая волна направлена вдоль `z`, поляризация по `x`.

## Выходные артефакты

Для `output_root` создаются:

- `raw/structured_lattice.jsonl`, `raw/structured_lattice.log` — события эксперимента;
- `raw/structured_lattice_summary.json` — итоговые метрики, параметры case, выбранный reference solver;
- `raw/structured_lattice_residual_histories.json` — истории невязок;
- `tables/structured_lattice_solver_runs.csv` — таблица solver metrics;
- `figures/structured_lattice_*` — scalar/vector field slices, RCS Cartesian/polar, residual norm plot.

## Ограничения

Unit-тесты используют малые сетки, например `N=6` или `N=8`, и не запускают рабочий `100^3` сценарий. Рабочий запуск `100x100x100` должен быть явным, поскольку он дорогой для CPU.
