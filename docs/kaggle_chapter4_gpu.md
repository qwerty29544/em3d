# GPU-запуск экспериментов главы 4 в Kaggle

Блокнот `notebooks/em-solver-farfield-validation-kaggle.ipynb` предназначен для
воспроизводимого запуска протоколов V1–V4 на одном NVIDIA GPU в Kaggle.

## Требования к сеансу

В настройках Notebook необходимо включить `Accelerator: GPU` и `Internet: On`.
Блокнот клонирует указанную ветку `qwerty29544/em3d`, фиксирует фактический
commit SHA, устанавливает пакет в editable-режиме, проверяет CUDA/CuPy и только
после малого сквозного теста запускает публикационную серию.

## Конфигурация

Основные параметры находятся в первой кодовой ячейке:

- `REPOSITORY_REF` — ветка или тег;
- `PRECISION` — `double` для итоговых результатов, `single` для отдельных
  производительных прогонов после проверки точности;
- `SOLVER_GRID_SIZE` — рабочая сетка V1–V3;
- `MIE_GRID_SIZES`, `MIE_EPS_VALUES`, `MIE_K0A_VALUES` — серия V4;
- `MIE_BATCH_AXIS`, `MIE_BATCH_INDEX`, `MIE_BATCH_COUNT` — разбиение полной
  серии Ми между независимыми Kaggle-сеансами.

Например, при `MIE_BATCH_AXIS="k0a"` и `MIE_BATCH_COUNT=3` следует выполнить три
сеанса с индексами `0`, `1`, `2`. Каждый архив содержит одинаковый commit SHA и
самостоятельный манифест.

## GPU-путь

Основное БПФ-действие оператора, итерационные решатели и прямое вычисление
дальней зоны выполняются на активном CuPy-бэкенде. Для дальней зоны на host
копируется только итоговый массив по угловым направлениям, а не всё поле.
После каждого случая Ми необязательные device-массивы освобождаются, и кэш
CuPy очищается, что уменьшает вероятность накопления фрагментации памяти.

## Результаты

В `/kaggle/working/em3d_chapter4_results` создаются:

- `manifest.json` с commit SHA, версиями библиотек и CUDA-телеметрией;
- `kaggle_session.json` с параметрами партии;
- CSV-таблицы решателей, полей, ЭПР и проверки Ми;
- сырые JSON/NPZ;
- рисунки PNG/PDF/SVG;
- ZIP-архив и файл SHA-256.

Численные выводы делаются только по строкам `qualified=True`. Диагностические
запуски `max_iter`, `divergence_guard` и `breakdown_*` не используются для
равноправного сравнения полей и ЭПР.
